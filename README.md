# وتين — Wateen

تطبيق لمتابعة **التعافي والإجهاد والنوم والتوتر** من بيانات الساعة الذكية، على الآيفون (Apple Health / ساعة Apple) والأندرويد (Health Connect). يعمل كلياً على الجهاز بلا خوادم.

## المميزات

| الميزة | ما يحسبه |
|---|---|
| التعافي 0–100٪ | تقلّب النبض (50٪)، نبض الراحة أثناء النوم (25٪)، أداء النوم (15٪)، التنفس وحرارة الجلد (5٪ لكل منهما) مقارنةً بمعدلك في 30 يوماً |
| الإجهاد 0–21 | حِمل القلب طوال اليوم (صيغة بانستر على مخزون النبض) + الإجهاد المستهدف حسب التعافي |
| النوم | الاحتياج (أساسي + إجهاد الأمس + دَين النوم − القيلولة)، الأداء، المراحل، الكفاءة، الانتظام، موعد النوم المقترح |
| التوتر 0–3 | النبض أثناء السكون مقارنة بنبض الراحة، مع استبعاد التمارين والمشي |
| اليوميات | أثر كل عادة على تعافي اليوم التالي |
| الاتجاهات | 7/30/90 يوماً + ملخص أسبوعي |
| مراقبة الصحة | المؤشرات الليلية مقابل نطاقك المعتاد |
| عمر الجسم | تقدير من عادات آخر 30 يوماً |
| بيانات تجريبية | لتجربة التطبيق بلا ساعة |

اللغتان: العربية (افتراضياً) والإنجليزية.

## استيراد ملف بيانات

من الإعدادات ← «استيراد ملف بيانات» (أو من شاشة البداية) يقرأ التطبيق ملف JSON بصيغة `wateen-raw`، ويمرّ بنفس الحسابات التي تمرّ بها بيانات الساعة.

- `samples/wateen-sample-data.json`: ‏46 يوماً محاكية لساعة Apple (حِمل تدريبي زائد، زكام، سفر إلى لندن، ليلة بلا ساعة، سباق 10 كم، ويوميات مطابقة). يُعاد توليده بـ `python3 tool/make_sample_data.py`.
- الصيغة موثّقة في `lib/data/import_format.dart`. مع `"alignToToday": true` تُزاح التواريخ بأيام كاملة لينتهي الملف باليوم.

## البناء

كل البناء سحابي على GitHub Actions:

- **Android** (`.github/workflows/android.yml`): مع كل دفعة إلى `main` — تحليل، اختبارات، ثم `wateen.apk` و`wateen.aab`. أحدث APK في إصدار `android-latest`.
- **iOS** (`.github/workflows/ios.yml`): يدوياً أو عند وجود `[ios]` في رسالة الالتزام. بدون أسرار Apple يتحقق من البناء فقط؛ ومع الأسرار يوقّع ويرفع إلى TestFlight.

### خطوات الآيفون (مرة واحدة)

1. الاشتراك في Apple Developer Program.
2. في App Store Connect: **Apps ← +** وإنشاء تطبيق بمعرّف الحزمة `com.m3athrazaq.wateen`.
3. **Users and Access ← Integrations ← App Store Connect API**: إنشاء مفتاح بصلاحية **Admin** وتنزيل ملف `.p8`.
4. إضافة أسرار المستودع في GitHub: `ASC_KEY_ID`، `ASC_ISSUER_ID`، `ASC_KEY_P8` (محتوى الملف)، `APPLE_TEAM_ID`.
5. تشغيل سير iOS؛ يظهر البناء في TestFlight بعد المعالجة.

### النشر في Google Play

- ارفع `wateen.aab`، وفعّل Play App Signing.
- أكمل نموذج **Health apps declaration** وأرفق سياسة الخصوصية (`docs/privacy-policy.md`).
